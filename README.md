# Student Skill Exchange

Peer-to-peer frontend for students to offer skills, find teachers, request exchanges, chat, schedule sessions, and rate partners.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL, then use **Continue as Demo User** or register a new profile.

Demo login also works with:

- Email: `ganesh@demo.edu`
- Password: `demo123`

Data is stored in `localStorage` so the demo can be connected to a Node.js / Express / MongoDB backend later.
